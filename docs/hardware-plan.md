# Подключение ESP32-P4-NANO

Назначения сверены с [официальной схемой Waveshare](https://files.waveshare.com/wiki/ESP32-P4-NANO/ESP32-P4-NANO-schematic.pdf) и закреплены в `main/board.h`. Подключение выполняется при полностью снятом питании.

Проверенная конфигурация платы: ESP32-P4 chip revision v1.3, 16 MB Flash, 32 MB PSRAM. Номер ревизии чипа не определяет маркировку печатной платы. Перед сборкой сверьте модель платы, ориентацию контакта 1 и подписи разъёмов.

Обозначение **P1.21** означает контакт 21 разъёма P1, а не GPIO21.

## ST7789

Профиль дисплея: SPI 240×320, RGB565, питание 3,3 В, встроенное питание подсветки без отдельного BL. MISO не используется.

| Контакт дисплея | ESP32-P4 | Контакт платы |
| --- | --- | --- |
| VCC | 3V3 | P1.1 |
| GND | GND | P1.25 |
| SCL / SCLK | GPIO2 | P2.11 |
| SDA / MOSI | GPIO3 | P2.9 |
| CS | GPIO26 | P1.21 |
| DC | GPIO5 | P1.11 |
| RES / RST | GPIO20 | P1.13 |

SCL/SDA на таком модуле обозначают SPI clock/data. Сигналы имеют уровень 3,3 В. Для этого профиля VCC подключается к 3V3. Контакт ESP_LDO_VO4 на P2.2 используется встроенной периферией и не является постоянным питанием TFT.

Если модуль имеет отдельный BL или другое питание, его подключение следует сверить с документацией конкретного модуля.

Драйвер использует SPI2, mode 0, 20 MHz, RGB, включённую инверсию, swap XY и mirror X, нулевые смещения. Итоговая ориентация: 320×240. NTSC 320×224 выводится с полями по 8 строк; H32 шириной 256 пикселей имеет поля по 32 пикселя.

### GPIO26

GPIO26 применяется как CS. Его альтернативная функция USB Full-Speed на паре GPIO26/27 отключается при настройке цифрового GPIO. Состояние USB pad проверяется при старте и после инициализации драйверов.

USB-C используется для загрузки и мониторинга платы; UART0 GPIO37/38 зарезервированы. Прошивка не запускает USB-host на штатном USB-A.

## Кнопки

| Кнопка | GPIO | Контакт платы |
| --- | --- | --- |
| ↑ | GPIO21 | P1.15 |
| ↓ | GPIO22 | P1.16 |
| ← | GPIO23 | P1.7 |
| → | GPIO32 | P1.23 |
| A | GPIO46 | P2.17 |
| B | GPIO47 | P2.15 |
| C | GPIO48 | P2.16 |
| Start | GPIO4 | P1.12 |

Каждая нормально разомкнутая кнопка замыкает свой GPIO на общий GND, например P1.25. Включена внутренняя подтяжка к 3,3 В; нажатие соответствует LOW. У четырёхконтактной тактовой кнопки выбираются контакты, которые соединяются при нажатии.

Опрос выполняется раз в 1 мс; изменение принимается после 5 мс стабильного уровня. Поддерживаются одновременные нажатия. A/B/C/Start соответствуют трёхкнопочному контроллеру Mega Drive.

## Штатные устройства

| Устройство / сигнал | GPIO / ресурс |
| --- | --- |
| ES8311 I2C SDA / SCL | 7 / 8, адрес шины 0x18 |
| I2S DOUT, ESP32-P4 → ES8311 | 9 |
| I2S LRCK / WS | 10 |
| I2S DIN микрофона, в игре не используется | 11 |
| I2S BCLK / MCLK | 12 / 13 |
| NS4150B PA_CTRL | 53, HIGH включает усилитель |
| microSD D0 / D1 / D2 / D3 | 39 / 40 / 41 / 42 |
| microSD CLK / CMD | 43 / 44 |
| microSD питание | GPIO45 LOW включает питание; LDO4 задаётся 3300 мВ |
| C6 SDIO D0-D3 / CLK / CMD | 14-17 / 18 / 19 |
| C6 boot / reset | 6 / 54 |
| UART0 TX / RX | 37 / 38 |
| RTC кварц | 0 / 1 |
| Ethernet | 28-31, 34-35, 49-52 |

Динамик 8 Ом, 2 Вт подключается к штатному двухконтактному разъёму MX1.25. Обе клеммы являются выходами мостового усилителя; ни одна не подключается к GND. ES8311 и NS4150B обеспечивают монофонический тракт.

GPIO34-38 являются strapping-выводами. Для внешних кнопок и дисплея они не используются. Неиспользуемый C6 удерживается в reset; его Flash не записывается.

В `board.h` проверяются 13 уникальных управляющих GPIO и отсутствие пересечений с защищёнными выводами. После драйверов и SDMMC проверяются подтяжки восьми входов кнопок и отключение USB-FS для GPIO26.

## Скорость изображения

RGB565 кадр 320×224 содержит 143 360 байт. Без учёта команд и пауз:

| SPI | Минимальное время передачи | Теоретический предел |
| --- | --- | --- |
| 20 MHz | 57,344 мс | 17,44 кадра/с |
| 40 MHz | 28,672 мс | 34,88 кадра/с |
| 80 MHz | 14,336 мс | 69,75 кадра/с |

Полный кадр 320×240 при 20 MHz требует минимум 61,44 мс. Рабочее значение по умолчанию: 20 MHz. Возможность 40/80 MHz зависит от модуля и проводки.
