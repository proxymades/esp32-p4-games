# esp32-p4-games

Эмулятор Sega Mega Drive / Genesis для **Waveshare ESP32-P4-NANO** на ESP-IDF. Первый целевой сценарий: Comix Zone с SPI-дисплеем ST7789, восемью физическими кнопками, microSD и штатным звуком ES8311/NS4150B.

В репозитории находятся исходники, настройки сборки и инструкции. ROM-файлы и готовые бинарные образы не распространяются. Для запуска требуется собственный несжатый ROM.

## Оборудование

- Waveshare ESP32-P4-NANO: ESP32-P4 revision 1.x, 16 MB Flash, 32 MB PSRAM. Проверенная конфигурация: чип v1.3.
- SPI TFT ST7789 240×320, RGB565, питание 3,3 В. В игре используется альбомная ориентация 320×240.
- microSD с FAT32.
- Кнопки ↑, ↓, ←, →, A, B, C, Start.
- Динамик 8 Ом, 2 Вт на штатном разъёме платы.

[Таблицы GPIO, питание и встроенная периферия](docs/hardware-plan.md).

## Быстрый запуск с macOS

Установите ESP-IDF **5.4.4** с инструментами для `esp32p4`. Скрипты поддерживают стандартное окружение ESP-IDF и Espressif Installation Manager.

```bash
git clone https://github.com/proxymades/esp32-p4-games.git
cd esp32-p4-games
bash scripts/build.sh play
```

Подготовьте на FAT32-карте файл `roms/comix_zone.bin`: это несжатый Mega Drive ROM, переименованный в `comix_zone.bin`. Установите карту в выключенную плату.

Подключите штатный USB-C, выберите порт и запишите собранную прошивку:

```bash
ls /dev/cu.usb*
bash scripts/flash.sh play /dev/cu.usbmodemXXXXXXXXXXX
```

Замените пример порта на порт своей платы. После загрузки нажмите Start.

[Полная инструкция сборки, настройки, загрузки и восстановления](docs/build-macos.md). [Поэтапная проверка оборудования и ядра](docs/testing.md).

## Работа прошивки

- ROM полностью загружается с microSD в PSRAM. После чтения карта размонтируется и её питание отключается.
- Размер, заголовок и reset vector проверяются; SHA-256 прочитанного файла выводится в журнал.
- При ошибке карты форматирование не запускается. После установки карты или исправления файла нужен Reset.
- Кнопки опрашиваются раз в 1 мс, дребезг подавляется после 5 мс стабильного уровня.
- Звук YM2612 и SN76489 синтезируется с синхронизацией по эмулируемым тактам и выводится через I2S DMA, 48 kHz, 16 bit, mono.
- Громкость по умолчанию: **95%**. Она регулирует музыку и эффекты вместе.
- Режим ST7789 по умолчанию: SPI 20 MHz. В измеренном запуске передача 320×224 занимала около 60 мс, то есть около 16,6 кадров изображения/с. Логическая скорость NTSC составляла около 59,9 кадров/с: при занятых SPI-буферах пропускается пиксельная работа, CPU, состояние VDP и звук продолжают выполняться.

Увеличение частоты SPI требует проверки конкретного TFT-модуля и проводки. Эта конфигурация SDK предназначена для ранних ESP32-P4 revision 1.x; она не является готовой конфигурацией для rev 3.x.

## Исходники и зависимости

Ядро Gwenesis закреплено на снимке из ESP32_P4_Launcher; оригинальные файлы и их хеши находятся в `components/gwenesis/`. Единственный внешний компонент приложения: `espressif/esp_codec_dev` **1.5.7**.

- [Устройство порта и изменения ядра](components/gwenesis/PORTING.md)
- [Происхождение исходников и лицензионные уведомления](THIRD_PARTY_NOTICES.md)

Проект использует прямые драйверы ESP-IDF. Для запуска с microSD не требуются Launcher, PAPP, LVGL или сетевые службы.
